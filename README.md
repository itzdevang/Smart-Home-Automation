🏠 Smart Home Automation System

This project is an Arduino-based Smart Home Automation System designed to improve home security, convenience, and energy efficiency by integrating multiple sensors and automation features into a single embedded system.


✨ Features: 


🚪 Automatic Door Control using an Ultrasonic Sensor and Servo Motor.

🚶 Motion Detection using a PIR Sensor to control a DC Motor/Alarm.

💡 Automatic Lighting System using an LDR Sensor that turns the LED ON in low-light conditions.

🌡️ Temperature Monitoring using a Temperature Sensor with Red/Green LED indicators for high and normal temperatures.

📟 16x2 LCD Display to show real-time sensor readings and system status.

🖥️ Serial Monitor Output for continuous monitoring and debugging.



🛠️ Technologies Used:


Arduino Uno

Embedded C (Arduino IDE)

Servo Library

LiquidCrystal Library

Ultrasonic Sensor

PIR Motion Sensor

LDR Sensor

Temperature Sensor (LM35)

Servo Motor

LCD 16x2 Display

LEDs


📌 Working:


Detects nearby objects and automatically opens the door using a servo motor.

Detects human movement and activates the connected motor/alarm.

Automatically switches ON the light when the surrounding environment becomes dark.

Continuously monitors room temperature and indicates the status using LEDs.

Displays all sensor readings and system status on the LCD screen.
